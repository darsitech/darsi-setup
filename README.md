# darsi-setup

## عن Darsi

يمكنك زيارة تطبيق Darsi وتجربته مباشرة عبر الويب:

[فتح تطبيق Darsi](https://darsi-dz-960.netlify.app/)

## تنزيل إصدار

لتنزيل ملفات الإعداد أو التثبيت، افتح صفحة إصدارات هذا المستودع:

[الانتقال إلى صفحة الإصدارات](https://github.com/darsitech/darsi-setup/releases)

1. افتح أحدث إصدار من القائمة.
2. من قسم **Assets (الملفات)**، اختر الملف المناسب لجهازك ونظام التشغيل لديك.
3. انقر على اسم الملف لبدء التنزيل.
4. بعد اكتمال التنزيل، فك ضغط الملف إذا كان مضغوطًا، ثم اتبع تعليمات الإصدار.

إذا لم تظهر ملفات ضمن **Assets**، فهذا يعني أن ملفات التثبيت غير متاحة لهذا الإصدار حاليًا. يمكنك استخدام تطبيق Darsi عبر الموقع أعلاه.
